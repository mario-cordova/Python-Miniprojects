# Small Python Scripts

A collection of small Python scripts built for practice and everyday use, covering topics like user input, functions, GUIs, and basic data management.

## Projects

### `temperature_converter`
A temperature converter built with user input, functions, and the `math` module.

### `account_creator`
A script that simulates creating a fake account with a custom username and password, then "logs in" to a fictional program. The interface is built with `Tkinter`.

### `teacher_tool`
A basic tool for calculating work hours and assigning groups. Ideal for use by a single teacher.

### `teacher_tool_advanced`
An advanced version of the teacher tool. It calculates hours, assigns subjects, and assigns homeroom groups, using the `Options` module. Ideal for organizing the entire teaching staff of a school or institution.

## Requirements

- Python 3.x
- Tkinter (included with most Python installations)

## Usage

Clone the repository and run any script from the terminal:

```bash
python script_name.py
```
